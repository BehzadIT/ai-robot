# Hardware Evidence Procedures

Procedures are reusable specifications; completed observations live in a new,
append-only evidence bundle. Every physical procedure must state the goal,
physical reason, tools/PPE, safe setup, steps, expected result and tolerance,
failure indications, stop conditions, decision impact, and retained evidence.

Unknown identity, missing isolation, unsuitable instruments, missing PPE or
workholding, or lack of a reliable stop path produces `blocked`. It is not a
reason to lower the procedure standard.
