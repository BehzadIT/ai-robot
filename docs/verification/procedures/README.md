# Hardware Evidence Procedures

Procedures are reusable specifications; completed observations live in a new,
append-only evidence bundle. Every physical procedure must state the goal,
physical reason, tools/PPE, safe setup, steps, expected result and tolerance,
failure indications, stop conditions, decision impact, and retained evidence.

Unknown identity, missing isolation, unsuitable instruments, missing PPE or
workholding, or lack of a reliable stop path produces `blocked`. It is not a
reason to lower the procedure standard.

## US-002 procedures

- [`US002-PROC-001`](US002-PROC-001-unpowered-identity.md): non-energizing
  visual identity and overview capture for all required component packs, with
  unknown high-current isolation treated as inaccessible.
- [`US002-PROC-002`](US002-PROC-002-unpowered-continuity.md): power-isolated
  harness continuity mapping after exact identities are known.
- [`US002-PROC-003`](US002-PROC-003-powered-encoder-levels.md): blocked powered
  encoder-level qualification with explicit prerequisites.
- [`US002-PROC-004`](US002-PROC-004-charger-display-identity.md): separately
  approved charger-display inspection with no battery connected.
