# BOM And Parts Status

## Purpose
Provide a working bill of materials view focused on what matters to future engineering work.

## Current status
- `Implemented / current`: Pico 2 W, ESP32 bridge, Cytron MDD10A, Pololu 37D motors, battery pack, Android app.
- `Available inventory`: sensors, tools, prototyping parts, mechanical hardware.
- `Legacy / uncertain`: some items in the exhaustive component list are not part of the active robot build.

## Core current parts
- Raspberry Pi Pico 2 W
- ESP32-DevKitC-class board
- 2x Pololu 37D 30:1 motors with encoders
- Cytron MDD10A
- 4S2P LiFePO4 pack
- DALY-family BMS
- Panther iQLoad EVO 5 charger

## Additional available parts
- HC-SR04
- VL53L0X
- DYP-A02-V2.0
- bench PSU, multimeter, connectors, brackets, washers, FR-4, and workshop hardware
