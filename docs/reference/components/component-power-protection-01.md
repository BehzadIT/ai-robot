# Power Protection And Disconnect

Registry ID: `component-power-protection-01`

This record represents a suspected documentation gap, not a claim that a
particular fuse or disconnect is absent. US-002 needs an as-built map from pack
through BMS, fuse/protection, switch/disconnect, connectors, conductors, motor
driver, and logic supplies.

Powered control and motion work remain blocked until a reachable action can
remove motor authority without approaching moving tracks or exposed
conductors. Record markings, conductor gauge, termination, accessibility, and
continuity before attempting a functional emergency-disconnect test.
