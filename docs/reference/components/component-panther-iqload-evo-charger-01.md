# Panther iQLoad EVO Charger

Registry ID: `component-panther-iqload-evo-charger-01`

The project reports an iQLoad EVO 5. The retained manual describes a 5 A
maximum 12 V output, a LiFePO4 program reaching 14.6 V, and later monitoring or
limited repeat-charge phases. This conflicts with the project note stating
that trickle mode is disabled.

Record the physical label and selected display mode before use. Charger
qualification must consider exact pack cells, 2P charge-current capability,
BMS configuration, protection, fire readiness, and the manufacturer's battery
instructions. Until those inputs exist, the correct result is `blocked`, not a
trial charge.
