# Tracked Chassis

Registry ID: `component-tracked-chassis-01`

The base is documented as a double-layer aluminum suspension crawler. Stock
520 motors and controller data are legacy; the current robot is reported to use
the Pololu/Cytron drivetrain.

Expansion dimensions, motor-hole offsets, bracket placement, and shaft-adapter
changes are design/project notes rather than an as-built record. Photograph
and measure the installed revision before fabricating replacements. Cutting or
drilling requires compatible tooling, secure workholding, backing, debris
control, deburring, and task-appropriate PPE.
