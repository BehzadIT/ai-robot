# ESP32 Development Board

Registry ID: `component-esp32-dev-board-01`

The ESP32 owns wireless gateway, telemetry, controller connectivity,
normalization, diagnostics, and bounded transport. It does not own motor
control or safety decisions.

The repository targets classic `esp32`, but that does not identify the exact
development board, module, USB/UART bridge, regulator, or exposed pins. Close
`Q-US002-004` with clear front/rear/module markings before treating a board
manual or pinout as applicable.
