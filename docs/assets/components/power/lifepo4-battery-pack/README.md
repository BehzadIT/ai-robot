# 4S2P LiFePO4 Battery Pack

The pack is owner-reported as eight 18650 LiFePO4 cells in 4S2P. Exact cells,
construction revision, insulation, interconnects, temperature sensing, fuse,
and disconnect remain unverified.

The retained cell specification is only a candidate. Do not unwrap or
dismantle the pack solely to identify the cells. Prefer purchase records,
construction photographs, and safely visible labels.

Charging remains blocked until cell, BMS, charger, protection, selected mode,
and current compatibility are established. The candidate source has not been
curated into this documentation.
