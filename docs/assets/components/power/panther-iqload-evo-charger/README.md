# Panther iQLoad EVO Charger

The project reports an iQLoad EVO 5, but the physical label and selected
program have not been verified. Record both before use.

Charger qualification depends on the exact cells, 2P charge-current capability,
BMS configuration, protection, fire readiness, and manufacturer instructions.
Until those inputs exist, the correct outcome is blocked rather than a trial
charge.

The EVO 5/7 family manual has not been curated into this documentation.
