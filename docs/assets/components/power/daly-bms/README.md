# Installed DALY-Family BMS

Project records contain incompatible candidate identities. The retained DALY
manual covers a broad product family; it does not prove installed current
rating, cell-count range, connectors, balancing, or communications options.

Photograph or transcribe the complete label and connectors before applying a
wiring diagram, cable, application setting, or protocol. Do not disconnect
sampling leads merely to identify the unit, and do not assume a BMS regulates
charger current.

The family manual has not been curated into this documentation.
