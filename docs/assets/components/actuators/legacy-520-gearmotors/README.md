# Legacy 520 Encoder Gearmotors

These motors are historical drivetrain references and must not supply current
Pololu 37D control constants. Their exact manufacturer and present inventory or
condition remain unknown.

The tracked-chassis source contains legacy motor information but has not been
curated for this component. See the registered copy in the
[tracked-chassis pack](../../mechanical/tracked-chassis/vendor/suspension-crawler-technical-parameters.pdf).
