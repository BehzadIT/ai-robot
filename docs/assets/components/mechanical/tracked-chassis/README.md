# Tracked Chassis

The base is documented as a double-layer aluminum suspension crawler. Stock
520 motors and controller data are legacy; the current robot is reported to use
the Pololu/Cytron drivetrain.

Expansion dimensions, hole offsets, bracket placement, and shaft-adapter
changes are project notes rather than an as-built record. Photograph and
measure the installed revision before fabrication. Cutting or drilling requires
compatible tooling, secure workholding, debris control, deburring, and PPE.

The vendor manual has not been curated into this documentation.
