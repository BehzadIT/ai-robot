# Embedded Learning Notes

This directory holds concise, reusable concepts that are expensive to relearn
and directly affect robot decisions. It is not a second manual library.

A useful note explains the concept, its role in this robot, a software analogy
and its limit, physical failure behavior, how to observe or measure it, and links
to authoritative standards, manuals, datasheets, or project evidence.

Keep story-specific teaching in the story or conversation. Register canonical
PDFs and manuals through the source registry and link them instead of copying
them here.
