# Repository Skills

The AI robot workspace uses six focused skills instead of persistent
specialist-agent personas:

- `$refine-story`: capture and refine the story definition.
- `$plan-story`: create its deterministic implementation plan and make it Ready.
- `$execute-story`: implement a Ready story with risk-matched evidence.
- `$review-story`: review readiness, implementation, and completion claims.
- `$embedded-mentor`: teach decision-relevant embedded and physical concepts.
- `$curate-component-documentation`: curate project-relevant component sources.

Skills share the active contracts in `docs/backlog/workflow.md` and
`docs/operations/human-agent-working-contract.md`, including the consequential
decision and meaningful handoff templates. Their external practice basis is in
`docs/operations/human-agent-interaction-practices.md`. Platform-specific work
also follows the nearest child repository's `AGENTS.md`.
