# Embedded Diagram Catalog

Use system-context for ownership; deployment for processors/links; data-flow for
transformations; sequence for protocol/timing; state for lifecycle/recovery;
power-signal for voltage/ground/protection; task-graph for dependencies;
test-architecture for seams/doubles/evidence; fault-response for stop/recovery;
traceability for requirements to evidence. Mermaid does not replace schematics,
wiring tables, CAD, or measurement. Store `.mmd` beside generated `.svg`.
